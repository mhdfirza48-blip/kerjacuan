KERJACUAN - FIREBASE
1. Buat Firebase Web App.
2. Aktifkan Authentication > Email/Password.
3. Buat Firestore Database.
4. Isi firebase-config.js dengan konfigurasi project.
5. Isi ADMIN_UID dengan UID akun admin.
6. Ganti GANTI_ADMIN_UID di firestore.rules dengan UID yang sama.
7. Upload file-file ini ke GitHub.
Catatan: gunakan tugas yang legal dan jangan meminta password, OTP, recovery email, atau kredensial akun pihak lain.
